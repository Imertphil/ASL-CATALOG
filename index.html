ASL:CATALOG

American Sign Language Landmarks

A dictionary catalog storing 3D hand coordinates for American Sign Language. Each entry contains landmark keyframes rendered as a skeleton animation using canvas. You can search words, filter by category, sort data, view animations, edit sign details, and delete entries.

* Data Origin: All landmark keyframes were pre-extracted from original signing footage via an independent MediaPipe utility.
